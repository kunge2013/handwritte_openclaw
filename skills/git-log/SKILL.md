# Git提交日志查看

这是一个用于查看Git提交历史的技能工具，支持多种查询方式。

## 功能说明

该技能提供以下功能：
1. 查看最近N条提交记录（默认10条）
2. 查看特定作者的提交历史
3. 查看特定文件的提交历史
4. 支持自定义显示数量
5. 格式化输出，易于阅读

## 使用方法

### 基础用法

```
/git-log
```
查看最近10条提交记录，显示提交哈希、作者、日期和提交信息。

### 查看特定作者的提交

```
/git-log --author=张三
```
查看指定作者的提交历史。

### 查看特定文件的历史

```
/git-log --file=src/main.js
```
查看指定文件的所有提交历史。

### 自定义显示数量

```
/git-log --count=20
```
查看最近20条提交记录。

### 组合使用

```
/git-log --author=张三 --count=5
```
查看指定作者的最近5条提交。

```
/git-log --file=README.md --count=15
```
查看指定文件的最近15条提交历史。

## 输出格式

输出包含以下信息：
- 提交哈希（短格式）
- 作者名称
- 提交日期（相对时间）
- 提交信息

示例输出：
```
📝 Git提交日志

a1b2c3d - 张三 (2天前): 添加新功能
e4f5g6h - 李四 (3天前): 修复bug
i7j8k9l - 王五 (1周前): 更新文档
```

## 参数说明

- `--author=名字`: 筛选特定作者的提交
- `--file=路径`: 查看特定文件的提交历史
- `--count=数字`: 显示的提交数量（默认10）
- `--detail`: 显示详细信息（包括文件变更）

## 实现逻辑

当用户调用此技能时，系统会：

1. 解析用户提供的参数
2. 构建相应的git log命令
3. 执行命令并获取结果
4. 格式化输出结果

### 命令构建规则

- 基础命令：`git log --pretty=format:"%h - %an (%ar): %s" -n 10`
- 添加作者筛选：`--author="作者名"`
- 添加文件筛选：`-- 文件路径`
- 自定义数量：`-n 数字`
- 详细信息：`--stat` 或 `--name-status`

## 错误处理

- 如果不在git仓库中，提示用户当前目录不是git仓库
- 如果指定的文件不存在，提示文件未找到
- 如果指定的作者没有提交记录，提示未找到相关提交

## 示例场景

### 场景1：快速查看最近提交
用户：`/git-log`
输出：显示最近10条提交的简要信息

### 场景2：查看团队成员的工作
用户：`/git-log --author=张三`
输出：显示张三的所有提交记录

### 场景3：追踪文件变更历史
用户：`/git-log --file=package.json`
输出：显示package.json文件的所有修改历史

### 场景4：详细审查
用户：`/git-log --count=5 --detail`
输出：显示最近5条提交的详细信息，包括修改的文件列表
