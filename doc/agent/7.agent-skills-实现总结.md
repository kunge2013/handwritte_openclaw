## 设计特点

### 1. 模块化设计

每个模块职责单一，易于维护和扩展：
- `types.ts` - 纯类型定义
- `frontmatter.ts` - 解析逻辑
- `config.ts` - 配置管理
- `filter.ts` - 过滤逻辑
- `workspace.ts` - 集成管理

### 2. 渐进式披露

采用三级加载机制优化 token 使用：
- Level 1: 元数据 (始终在上下文中)
- Level 2: SKILL.md 正文 (按需加载)
- Level 3: 捆绑资源 (按需加载)

### 3. 安全性

多层安全机制：
- 路径验证和包含检查
- 输入验证和格式检查
- 文件大小限制
- 数量限制保护

### 4. 可扩展性

多种扩展方式：
- 自定义技能目录
- 技能过滤器
- 配置驱动
- 命令分发

### 5. 性能优化

多项性能优化：
- 路径压缩 (~5-6 tokens/skill)
- 二分查找优化裁剪
- 智能限制管理
- 缓存机制

## 使用方式

### 基础使用

```typescript
import {
  loadWorkspaceSkillEntries,
  buildWorkspaceSkillSnapshot,
} from './src/agents/skills/index.js';

const entries = loadWorkspaceSkillEntries('/path/to/workspace');
const snapshot = buildWorkspaceSkillSnapshot('/path/to/workspace');

console.log('Skills prompt:', snapshot.prompt);
```

### 高级使用

```typescript
import {
  loadWorkspaceSkillEntries,
  buildWorkspaceSkillSnapshot,
  SkillMatcher,
} from './src/agents/skills/index.js';

const entries = loadWorkspaceSkillEntries('/path/to/workspace');
const matcher = new SkillMatcher(['github', 'git', '!git-lfs']);
const filtered = entries.filter(e => matcher.matches(e.skill.name));

const snapshot = buildWorkspaceSkillSnapshot('/path/to/workspace', {
  entries: filtered,
  skillFilter: ['github', 'git'],
});
```
