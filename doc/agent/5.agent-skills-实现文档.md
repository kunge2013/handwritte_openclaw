# OpenClaw Agent Skills 实现文档

## 概述

本文档描述了 OpenClow Agent Skills 系统的实现细节和使用方法。

## 架构设计

### 核心模块

```
src/agents/skills/
├── types.ts          # 类型定义
├── frontmatter.ts    # 前置元数据解析
├── config.ts         # 配置管理
├── filter.ts         # 技能过滤
├── workspace.ts      # 工作区技能管理
└── index.ts          # 统一导出
```

### 设计原理

#### 1. 渐进式披露 (Progressive Disclosure)

技能系统采用三级加载机制，优化 token 使用：

```
Level 1: 元数据 (name + description)     始终在上下文中 (~100 tokens)
Level 2: SKILL.md 正文                  技能触发时加载 (<5k tokens)
Level 3: 捆绑资源                      按需加载 (无限制，脚本可执行)
```

#### 2. 模块化设计

每个模块职责单一：

- **types.ts** - 定义所有接口和类型
- **frontmatter.ts** - 解析 YAML 前置元数据
- **config.ts** - 管理配置和就绪性检查
- **filter.ts** - 提供技能过滤功能
- **workspace.ts** - 管理技能加载和快照构建

#### 3. 扩展性设计

系统支持多种扩展方式：

1. **自定义技能目录** - 通过配置添加额外技能源
2. **插件技能** - 插件可以提供技能
3. **技能配置** - 为特定技能提供配置
4. **技能命令** - 技能可以定义命令分发

## 核心功能

### 1. 技能加载

**函数**: `loadWorkspaceSkillEntries(workspaceDir, config?)`

功能：
- 从多个源加载技能 (workspace/.agents/~/.agents)
- 解析 SKILL.md 文件
- 提取前置元数据
- 构建技能条目

示例：

```typescript
import { loadWorkspaceSkillEntries } from './skills/index.js';

const skills = loadWorkspaceSkillEntries('/path/to/workspace');
console.log(`Loaded ${skills.length} skills`);

for (const entry of skills) {
  console.log(`- ${entry.skill.name}: ${entry.skill.description}`);
}
```

### 2. 技能快照

**函数**: `buildWorkspaceSkillSnapshot(workspaceDir, options?)`

功能：
- 构建技能系统状态快照
- 应用配置和过滤
- 生成提示词内容
- 支持版本管理

示例：

```typescript
import { buildWorkspaceSkillSnapshot } from './skills/index.js';

const snapshot = buildWorkspaceSkillSnapshot('/path/to/workspace', {
  skillFilter: ['github', 'git'],
  config: userConfig,
});

console.log('Skills prompt:', snapshot.prompt);
);
console.log('Included skills:', snapshot.skills.map(s => s.name));
```

### 3. 技能过滤

**类**: `SkillMatcher`

功能：
- 支持通配符匹配 (*)
- 支持排除模式 (!)
- 不区分大小写

示例：

```typescript
import { SkillMatcher } from './skills/index.js';

const matcher = new SkillMatcher(['github', 'git', '!git-lfs']);

console.log(matcher.matches('github'));        // true
console.log(matcher.matches('git'));           // true
console.log(matcher.matches('git-lfs'));       // false
```

### 4. 配置管理

**函数**: `resolveSkillConfig(config, skillKey)`

功能：
- 解析技能特定配置
- 支持环境变量覆盖
- 提供 API 密钥管理

示例：

```typescript
import { resolveSkillConfig } from './skills/index.js';

const config = {
  skills: {
    entries: {
      github: {
        enabled: true,
        apiKey: 'ghp_xxx...',
      },
    },
  },
};

const skillConfig = resolveSkillConfig(config, 'github');
console.log('GitHub skill enabled:', skillConfig?.enabled);
```

## 安全特性

### 1. 路径安全

- 使用 `realpath` 解析符号链接
- 验证技能路径在允许的根目录内
- 防止路径遍历攻击

### 2. 输入验证

- 所有输入都经过格式验证
- 使用正则表达式验证 URL、包名等
- 防止命令注入

### 3. 文件大小限制

- SKILL.md 文件大小限制 (默认: 256KB)
- 每个源最大技能数限制 (默认: 200)
- 提示词字符数限制 (默认: 30,000)

### 4. 资源限制

- 每个根目录最大候选数 (默认: 300)
- 提示词中最大技能数 (默认: 150)
- 最大候选数限制防止拒绝服务攻击

## 性能优化

### 1. 路径压缩

将绝对路径压缩为相对路径 (~)：

```
/Users/alice/.bun/.../skills/github/SKILL.md
→ ~/.bun/.../skills/github/SKILL.md
```

节省 ~5-6 tokens per skill × N skills ≈ 400-600 tokens total。

### 2. 智能裁剪

使用二分查找优化字符数限制：

```typescript
// 二分查找最大符合字符限制的技能数
let lo = 0;
let hi = skillsForPrompt.length;
while (lo < hi) {
  const mid = Math.ceil((lo + hi) / 2);
  if (fits(skillsForPrompt.slice(0, mid))) {
    lo = mid;
  } else {
    hi = mid - 1;
  }
}
```

### 3. 缓存机制

- 技能快照缓存
- 序列化操作防止并发问题
- 按需加载技能内容

## 使用示例

### 基础使用

```typescript
import {
  loadWorkspaceSkillEntries,
  buildWorkspaceSkillSnapshot,
} from './skills/index.js';

// 1. 加载技能
const entries = loadWorkspaceSkillEntries('/path/to/workspace');

// 2. 构建快照
const snapshot = buildWorkspaceSkillSnapshot('/path/to/workspace');

// 3. 使用提示词
console.log(snapshot.prompt);
```

### 高级使用

```typescript
import {
  loadWorkspaceSkillEntries,
  buildWorkspaceSkillSnapshot,
  buildWorkspaceSkillCommandSpecs,
  SkillMatcher,
} from './skills/index.js';

// 自定义配置
const config = {
  skills: {
    entries: {
      github: {
        enabled: true,
        apiKey: process.env.GITHUB_TOKEN,
      },
    },
    limits: {
      maxSkillsInPrompt: 100,
      maxSkillsPromptChars: 20000,
    },
  },
};

// 加载技能
const entries = loadWorkspaceSkillEntries('/path/to/workspace', config);

// 过滤技能
const matcher = new SkillMatcher(['github', 'git', 'code']);
const filtered = entries.filter(e => matcher.matches(e.skill.name));

// 构建快照
const snapshot = buildWorkspaceSkillSnapshot('/path/to/workspace', {
  entries: filtered,
  config,
});

// 构建命令规范
const commands = buildWorkspaceSkillCommandSpecs('/path/to/workspace', {
  entries: filtered,
});
```

### 集成到 Agent

```typescript
import { Agent } from './agents/agent.js';
import { buildWorkspaceSkillSnapshot } from './skills/index.js';

class SkillsAgent extends Agent {
  private skillsSnapshot?: import('./skills/types.js').SkillSnapshot;

  async initializeSkills(workspaceDir: string) {
    this.skillsSnapshot = buildWorkspaceSkillSnapshot(workspaceDir);
  }

  protected buildContext(): string {
    const baseContext = super.buildContext();
    const skillsContext = this.skillsSnapshot?.prompt || '';

    return `${baseContext}\n\n${skillsContext}`;
  }
}
```

1. 创建技能目录：

```bash

```

```
├── scripts/
│   └── script.sh
├── references/
│   └── doc.md
└── assets/
    └── icon.png
```

### 创建技能过滤器

```typescript
import { createSkillFilter } from './skills/index.js';

const filter = createSkillFilter({
  nameFilter: ['github', 'git', '!git-lfs'],
  tagFilter: {
    require: 'version-control',
    exclude: 'experimental',
  },
  customFilter: (name) => {
    return !name.startsWith('test-');
  },
});

const filtered = skills.filter(s => filter(s.skill.name, s.metadata?.tags));
```
