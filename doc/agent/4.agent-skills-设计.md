# OpenClaw Agent Skills 技能设计文档

## 概述

OpenClaw 的 Agent Skills 系统是一个模块化、可扩展的技能管理框架，用于扩展 AI Agent 的能力。该系统通过定义可重用的技能包（Skills），将专业知识、工作流程和工具集成到 Agent 中，使其能够处理特定领域的任务。

## 核心设计理念

### 1. 技能的定义

技能是自包含的模块化包，提供：
- **专业化工作流程** - 多步骤过程的特定领域指导
- **工具集成** - 与特定文件格式或 API 交互的说明
- **领域专业知识** - 公司特定知识、架构、业务逻辑
- **捆绑资源** - 脚本、参考文档和资产，用于复杂和重复性任务

### 2. 渐进式披露（Progressive Disclosure）设计

为了高效管理上下文窗口，技能系统采用三级加载机制：

```
Level 1: 元数据（name + description）     始终在上下文中（~100 tokens）
Level 2: SKILL.md 正文                  技能触发时加载（<5k tokens）
Level 3: 捆绑资源                      按需加载（无限制，脚本可执行）
```

### 3. 技能结构

每个技能目录的标准结构：

```
skill-name/
├── SKILL.md (必需)
│   ├── YAML 前置元数据（必需）
│   │   ├── name: (必需) - 技能名称
│   │   └── description: (必需) - 技能描述和触发条件
│   └── Markdown 正文（必需）- 使用说明
├── scripts/          (可选) - 可执行代码
├── references/       (可选) - 参考文档
└── assets/           (可选) - 输出资源
```

### 2. 工作区技能管理

#### 技能加载层次结构

系统从多个位置加载技能，按优先级合并：

```

1. extra (额外目录)
2. bundled (内置技能)
3. managed (管理技能)
4. agents-skills-personal (~/.agents/skills)
5. agents-skills-project (.agents/skills)
6. workspace (workspace/skills)
```

#### 技能限制

### 5. 技能安装系统

**文件**: `src/agents/skills-install.ts`

#### 安装流程

```
1. 查找技能条目
2. 收集安装扫描警告
3. 找到安装规范
- download 类型 → 下载安装
- 其他类型 → 命令安装
4. 前置检查（brew, uv, go）
5. 执行安装命令
6. 返回安装结果
```

#### 安装器支持

**Homebrew 安装**
```typescript
case "brew": {
  if (!spec.formula) {
    return { argv: null, error: "missing brew formula" };
  }
  return { argv: ["brew", "install", spec.formula] };
}
```

**Node 包安装**
```typescript
case "node": {
  if (!spec.package) {
    return { argv: null, error: "missing node package" };
  }
  return {
    argv: buildNodeInstallCommand(spec.package, prefs),
  };
}
```

**Go 模块安装**
```typescript
case "go": {
  if (!spec.module) {
    return { argv: null, error: "missing go module" };
  }
  return { argv: ["go", "install", spec.module] };
}
```

**uv 包安装**
```typescript
case "uv": {
  if (!spec.package) {
    return { argv: null, error: "missing uv package" };
  }
  return { argv: ["uv", "tool", "install", spec.package] };
}
```

**下载安装**
```typescript
case "download": {
  return { argv: null, error: "download install handled separately" };
}
```

#### 依赖安装

系统会自动安装所需依赖：
- **uv** - 如果需要 uv 但未安装，尝试通过 brew 安装
- **go** - 如果需要 go 但未安装，尝试通过 brew 或 apt 安装

#### 安全扫描

安装前会进行代码安全扫描：
```typescript
async function collectSkillInstallScanWarnings(entry: SkillEntry): Promise<string[]> {
  const summary = await scanDirectoryWithSummary(skillDir);
```

### 6. 归档提取

**文件**: `src/agents/skills-install-extract.ts`

#### 支持的归档格式

- **zip** - ZIP 压缩包
- **tar.gz** - gzip 压缩的 tar 包
- **tar.bz2** - bzip2 压缩的 tar 包

#### 安全措施

1. **路径检查** - 防止目录遍历攻击（zip-slip）
2. **元数据验证** - 提取前验证所有条目
3. **哈希验证** - 确保归档在提取过程中未被修改
4. **临时目录** - 使用临时目录进行提取，验证后再合并

#### tar.bz2 特殊处理

```typescript
if (archiveType === "tar.bz2") {
  // 1. 预读取归档列表
  const preflight = await readTarPreflight({ archivePath, timeoutMs });

  // 2. 检查每个条目的安全性
  for (let i = 0; i < preflight.entries.length; i += 1) {
    checkTarEntrySafety({
      path: entryPath,
      type: entryMeta.type,
      size: entryMeta.size,
    });
  }

  // 3. 验证归档哈希
  const hashFailure = await verifyArchiveHashStable({
    archivePath,
    expectedHash: preflightHash,
  });

  // 4. 使用临时目录提取
  return await extractTarBz2WithStaging({ ... });
}
```

## 技能生命周期

### 1. 加载阶段

```
1. 扫描技能目录（多个源）
2. 解析 SKILL.md 前置元数据
3. 解析 OpenClaw 元数据
4. 应用配置和过滤
5. 检查就绪性（环境、依赖）
6. 构建技能条目列表
7. 按优先级合并技能
```

### 2. 就绪性检查

```
1. 检查配置启用状态
2. 检查允许列表（内置技能）
3. 检查操作系统匹配
4. 检查二进制依赖（本地和远端）
5. 检查环境变量
6. 检查配置路径
7. 确定是否就绪
```

### 3. 提示词构建

```
1. 过滤禁用模型调用的技能
2. 应用技能数量限制
3. 应用字符数限制（二分查找）
4. 压缩技能路径
5. 格式化为提示词块
```

### 4. 安装阶段

```
1. 查找技能安装规范
2. 选择最佳安装方式
3. 安全扫描代码
4. 安装前置依赖
5. 执行安装命令
6. 返回安装结果和警告
```

## 安全特性

### 1. 路径安全

- **路径包含检查** - 确保技能文件在允许的根目录内
- **符号链接验证** - 使用 realpath 解析符号链接
- **路径压缩** - 减少信息泄露

### 2. 输入验证

- **格式验证** - 所有输入都经过严格的格式验证
- **路径遍历防护** - 防止 zip-slip 攻击
- **命令注入防护** - 命令参数经过转义

### 3. 代码扫描

- **危险模式检测** - 扫描技能代码中的危险模式
- **安装前警告** - 在安装前报告安全问题
- **可选深度扫描** - 用户可要求深度安全审计

### 4. 归档安全

- **哈希验证** - 确保归档在提取期间未被修改
- **临时目录** - 使用临时目录进行验证
- **条目验证** - 提取前验证所有归档条目

## 设计原则总结

### 1. 模块化

每个技能都是自包含的模块，可以独立开发、测试和部署。

### 2. 可扩展性

系统设计支持多种扩展方式：
- 自定义技能目录
- 插件技能
- 配置驱动的技能

### 3. 安全性

多层安全机制确保技能系统安全：
- 路径验证
- 输入验证
- 代码扫描
- 归档安全

### 4. 性能

通过渐进式加载和限制机制确保性能：
- 最小化上下文窗口占用
- 智能裁剪和优化
- 路径压缩

### 5. 用户体验

清晰的 CLI 接口和状态报告：
- 技能列表和详情
- 就绪性检查
- 安装辅助
